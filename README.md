A program that writes the funniest single-line resignation letter it can:
one line, one joke, from a lifeguard who finally learned to save himself
first. Built for the [make.fun](https://make.fun/c/u-kreutzx-the-one-line-exit-1dc652d1)
competition "The One-Line Exit".

## Run

```sh
python3 main.py
```

It writes the resignation line to `/output/entry.txt` — exactly one line,
1–140 characters, no trailing newline.

## The line

> After five years of watching the pool so nobody drowns, I am finally saving myself — I resign, effective immediately.
